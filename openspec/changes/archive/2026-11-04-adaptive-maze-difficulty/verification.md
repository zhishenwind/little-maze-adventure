# 验证记录

日期：2026-11-04（Asia/Shanghai）

## 需求与交付

用户确认先实现手机屏幕适配与结构难度的第一版。默认轻松冒险，三档上限为 6×8、8×10、10×12（列×行），4×4 独立为可跳过练习。小屏减少行列，每局固定尺寸；返回设置、旋转和窗口缩放不重生成。

纯 TypeScript 模型改为 cols/rows。随机生长树候选综合通关长度、有效岔路和错路深度评分，每局最多比较 64 个候选，练习最多 12 个。参数按网格容量缩放；所有候选都满足全连通、唯一解。

手机开始后收起设置、页头和装饰，保留返回设置、继续冒险、重试和方向操作。直接拖动在松手后进入专注布局，避免拖动中棋盘移动；旋转中止旧坐标手势，松手后可以续走。扩大头像抓取热区，方向按钮至少 44×44 CSS 像素。

## 难度抽样与性能

使用 xorshift 固定种子 20261104，每档 100 个样本。有效岔路只计解路径上能够进入至少两格深的非解支路，错路深度为这些支路最长距离的均值。

| 同为 6×8 | 平均路线步数 | 平均有效岔路 | 平均错路深度 |
| --- | ---: | ---: | ---: |
| 轻松 | 15.78 | 2.25 | 3.25 |
| 探索 | 16.54 | 3.01 | 4.21 |
| 挑战 | 19.54 | 4.00 | 5.03 |

同为 4×6 时平均有效岔路为 1.09、1.78、2.00，错路深度为 2.27、2.94、3.49，路线步数为 10.04、11.64、12.80。

| 各档上限 | 平均路线步数 | 平均有效岔路 | 平均错路深度 | 本机平均／最高生成时间 |
| --- | ---: | ---: | ---: | --- |
| 轻松 6×8 | 15.78 | 2.25 | 3.25 | 1.02 / 2.70ms |
| 探索 8×10 | 22.08 | 5.00 | 5.27 | 1.64 / 2.31ms |
| 挑战 10×12 | 32.60 | 7.04 | 6.75 | 2.38 / 2.58ms |

计时通过 Node 直接调用生成器并使用 `performance.now()`；这是本机样本，不代表低端手机性能。

## 边界与剩余事项

- 本轮验收是 Chrome 手机模拟和真实生产 Service Worker，尚未做真实儿童试玩、真机微信浏览器或微信小程序验收。难度参数是初版，后续根据伊一实际体验调整。
- 极矮视口以保留最低可操作网格为先，允许纵向滚动。进行中的大棋盘旋转后可按比例缩小，行列和进度保持，用户也可以主动开新局重新适配。
- 难度描述为统计目标，小尺寸不保证每张布局达到所有指标；筛选有固定次数上限。
- 不新增网络接口、第三方 SDK 或依赖，离线缓存边界未扩张。普通局域网 HTTP 仍仅在线可用；已有离线包需通过原有更新入口加载新版本。
- 当前 main 尚未包含已交付的离线和头像提交，本轮分支从现有已交付提交 ea30c9a 建立，以完整保留当前版本；未合并或重写历史。
