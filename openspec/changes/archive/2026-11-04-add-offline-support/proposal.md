# Proposal

## Why

游戏当前没有网络接口，逻辑与素材已全部在本地构建中，但浏览器刷新仍依赖服务器。用户希望首次联网访问时自动下载离线包，之后从浏览器缓存运行；未来加入接口或第三方 SDK 时再调整边界。

## What Changes

- 构建包含全部运行资源的离线包，首次自动保存，完成后才提示离线可用。
- 后续页面和资源优先从本地缓存加载，断网刷新、重新打开和完整游玩均可用。
- 显示保存中、离线可用、离线游玩、失败重试和不支持环境的真实状态。
- 新版本后台准备，提示用户主动更新，不中断正在进行的游戏；失败时保留当前可用版本。
- 增加基于生产构建和真实 Service Worker 的离线验证与使用说明。
- 非目标：缓存未来接口或第三方请求、保存未完成的一局、原生安装包、离线首次访问、绕过浏览器 HTTPS 要求。

## Capabilities

### New Capabilities

- `offline-play`：离线包首次保存、本地运行、状态反馈和版本更新。

### Modified Capabilities

无。既有迷宫、奖励与进度行为保持不变；离线刷新仍不恢复未完成的一局。

## Impact

影响 Vite 构建、Service Worker、离线状态组件、浏览器测试和文档。引入固定版本 Workbox 模块与项目内轻量构建集成。开发服务器不启用离线缓存；真实离线体验使用生产构建的 HTTPS 地址或 Remote-SSH 转发的 localhost 预览地址。
