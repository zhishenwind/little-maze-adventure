## 本轮交付

- 构建时编译独立模块 Worker，为实际 HTML、JS、CSS、SVG 与应用清单生成 SHA-256 预缓存清单，不通过 CDN 加载任何运行资源。

- 提供保存中、离线可用、离线游玩、失败重试与不支持环境的状态，缓存丢失后按资源清单补齐缺失内容。
- 新版本后台准备、用户主动激活；下载失败保留可用旧版本，不清除星星或音效偏好。
- 不添加接口或第三方运行时缓存，原有迷宫与奖励规则不变。
- 新增 `npm run offline` 和 Remote-SSH 4173 转发说明，保留开发环境在线热更新。

## 新增浏览器覆盖

1. 首次资源全部保存，后续在线刷新仅检查 Worker、不重复请求游戏资源；断网关闭页面后新开页面，全部主题、角色、难度、提示与通关可用，刷新保留星星和静音。
2. 真实服务器对资源返回 503，中断首次安装，不误报离线就绪；重试后可用且不影响当前角色位置。
3. 删除 Cache Storage 后识别不完整资源，重试保存成功，保留已有星星。
4. 模拟真实新版本修订，下载后不打断当前局；用户点击才刷新，新版激活后清除旧修订并保留星星。
5. 新版下载失败时，旧版仍可断网刷新。
6. GET／POST 接口与跨源请求不会进入游戏缓存，接口页面导航不返回游戏壳。
7. 手机断网后反复松手、续拖，正常通关且无横向溢出。
8. 开发环境与不安全上下文明确显示在线模式，不注册离线服务。

## 验证中修正的问题

缓存被清除后，立即注销再注册同一个 Worker 可能复用已有注册，无法可靠恢复同一修订。本轮改为让已受控 Worker 只补齐清单内缺失资源，并用真实缓存删除场景验证；首次安装失败、尚未受控时才重新注册。

## 使用边界

- 真实首次离线保存需 HTTPS 或 localhost。普通 HTTP 局域网地址继续在线运行，不会误报离线可用。Remote-SSH 用户转发 4173 到本机，再访问 http://localhost:4173/。
- 已在本机 Google Chrome 验证自动化和浏览器重启；手机为 Chrome 触屏模拟，未声明已在实体 iPhone／微信内置浏览器验证。
- 缓存按浏览器与地址隔离，用户清理网站数据或浏览器回收缓存后需联网重新保存；当前局仍遵循既有规则，不跨刷新恢复。
- 本轮没有上线部署，也没有验证各平台安装到桌面的能力；应用清单只提供独立窗口等基础信息。
